# Rozgar Jobs — iPhone App (Free Build)

Ye hamari job app ka iOS project hai. GitHub ka muft Mac computer isse
iPhone wali app file (IPA) banata hai.

## IPA kaise banayein (har baar)

1. Upar **Actions** tab par jao
2. **Build iPhone App (Free)** chuno
3. **Run workflow** dabao
4. Kuch minutes rukho — khatam hone par neeche **Artifacts** me
   **RozgarJobs-iPhone-IPA** milega, use download kar lo

## iPhone par install

Andar wali file **iPhone-Par-Free-Install-Guide.txt** me poora tareeka
(SideStore ke saath, bilkul free) step-by-step likha hai.
